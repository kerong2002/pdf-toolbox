📄 PDF 工具箱
🔒 全部在你的瀏覽器內處理，檔案不會上傳到任何伺服器

合併 PDF

把多個 PDF 接成一份。用上下箭頭調整順序，順序就是合併的順序。

拖曳 PDF 到這裡，或點擊選擇（可多選）

    分割 / 擷取頁面

    從一份 PDF 取出你要的頁面，或拆成單頁。

    拖曳一份 PDF 到這裡，或點擊選擇

      留空 = 全部。支援 1-3、5、8-（第 8 頁到最後）

      頁面管理

      看縮圖、刪頁、搬動順序、單頁旋轉，改完匯出新的 PDF。

      拖曳一份 PDF 到這裡，或點擊選擇

        PDF → 圖片

        每頁輸出一張 PNG 或 JPG。超過一張會打包成 ZIP。

        拖曳 PDF 到這裡，或點擊選擇（可多選）

          圖片 → PDF

          把 PNG / JPG 合成一份 PDF，一張圖一頁。順序可調。

          拖曳圖片到這裡，或點擊選擇（可多選）

            加浮水印

            在每頁疊上文字，例如「僅供申貸使用」。

            ⚠️ 內建字型只支援英文、數字與符號。中文浮水印會失敗（PDF 標準字型不含中文字符）。請改用英文，例如 FOR BANK USE ONLY。
            拖曳 PDF 到這裡，或點擊選擇（可多選）

              壓縮 PDF

              把每頁重新畫成 JPG 再包回 PDF。對掃描檔、照片型 PDF 很有效。

              ⚠️ 這是破壞性壓縮：處理後文字會變成圖片，無法再選取或搜尋。原檔請留著。
              拖曳 PDF 到這裡，或點擊選擇（可多選）
